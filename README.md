# CropGuard Edge — AI Crop Disease Detection

An ML-powered crop disease detection system built for smallholder farmers 
in Kenya, designed to work in low-connectivity environments.

**Live demo:** https://cropguard-edge.vercel.app

## What it does
- Classifies crop diseases from images using a trained ML model
- Designed for edge deployment — works with limited internet access
- Targets the Kenyan smallholder farming context directly

## Tech stack
Python · scikit-learn · Vercel

## Project structure
- `data/` — training datasets
- `models/` — saved model files  
- `notebooks/` — EDA and model training
- `scripts/` — inference and utility scripts
